This program is inspired by the awe-inspiring oscilloscope. It is a very simple rendition that can be simply described as a ADC wave converter. It takes in a analog signal and convert it into a digital waveform. This is made via a STM32 Microcontroller using CubeMX and STM IDE environments.

The Microcontroller used is a NUCLEO-C071RB connected to an inland 128x64 OLED display and an AC source ie. joystick, function generator, etc.
